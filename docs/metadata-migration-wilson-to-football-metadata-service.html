What changed vs the original 7-step plan

Corrections from reading the code

  • Dropped the SQLModel-on-wilson's-tables layer. son already gives Django-ORM access to wilson's live DB in production — no translation layer to build.
  • Removed direct writes to wilson. A foreign ORM would bypass Django signals, custom save() (auto-created run-parameters, DataCollection, 12h uniqueness) and auto timestamps. Read-only sidesteps all of it.
  • No DB "recreation". The service already has a redesigned provider-scoped schema (ADR 0002); the endgame is a synced dedicated DB, not a rebuild.
  • wilson maps into the identity model as provider='wilson', preserving wilson-PK ↔ new-PK.
  • Two early risks: son (Django 4.2, ≤ Py 3.12) inside a Py 3.13 async service — confirm or isolate; and Pulumi work to grant read access + network reach to wilson's Aurora.
