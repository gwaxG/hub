Integration checks

Named structural checks, not a score. fail is something to fix before merging, warn is a deliberate decision to make, note is context worth knowing.

Is it a slope?

Repo-level aggregates at the merge base versus at this head. A feature that integrates well moves these barely at all; a slope shows up as several amber arrows at once.

Where the feature sits

The whole dependency graph, with this change emphasised — new nodes ringed in white, touched nodes lit, everything else dimmed to context. Lime edges are imports this change introduced. Click a node to isolate its neighbours; use the buttons to narrow to the feature and its immediate blast radius.

New imports

Dependency matrix of the head revision, topologically ordered. Lime cells are imports this change added; amber cells below the diagonal are back-edges (cycles).

Layer coupling, before and after

Imports from each layer (row) into each layer (column) at this head. Lime = a pair that gained imports, bold lime = a pair that had none at all before this change.

Nodes the feature added or touched

Deltas against the merge base. Δfan-in rising on an existing node means the feature reached into it; ΔMI falling and Δcc rising mean it got harder to maintain.

Changed files

Every non-deleted Python file in the diff, worst churn × complexity first. T marks a test file.
